# Agri ZKP Privacy Layer

**An Application Privacy Layer Using Zero-Knowledge Proofs for Confidential Data Interaction in Multi-Chain Agricultural Blockchain Systems**

Farmers submit crop compliance data privately. The system generates a **Groth16 zero-knowledge proof** (Circom + SnarkJS), verifies it on a **local Ethereum** network (Hardhat), and stores only **crop, proof hash, verification result, and timestamp** — never the actual yield, temperature, inventory, pesticide, or price values.

## Prerequisites

Install the following before running the project:

| Tool | Version | Purpose |
|------|---------|---------|
| [Node.js](https://nodejs.org/) | 18+ | Backend, frontend, Hardhat |
| [MongoDB](https://www.mongodb.com/try/download/community) | 6+ | Database |

### Install Circom (required for ZKP)

```bash
# Install Rust first: https://rustup.rs/
cargo install circom
```

### Install MongoDB

- **Windows:** Download MongoDB Community Server and run `mongod`
- **macOS:** `brew install mongodb-community && brew services start mongodb-community`
- **Linux:** `sudo systemctl start mongod`

## Installation

Open a terminal in the project root:

```bash
# 1. Install all Node.js dependencies
npm run install:all

# 2. Build ZKP circuit (compile Circom + Groth16 trusted setup)
cd zkp
npm run build
cd ..

# 3. Compile and deploy Solidity contracts
cd contracts
npm run compile
# Start local blockchain in a separate terminal:
npm run node
# Then deploy (in another terminal):
npm run deploy
cd ..

# 4. Configure backend environment
copy backend\.env.example backend\.env   # Windows
# cp backend/.env.example backend/.env  # macOS/Linux
```

## Usage Flow

### Farmer Dashboard (`/`)

1. Select a crop from `crop_rules.csv`
2. Enter: Yield, Temperature, Inventory, Pesticide, Price
3. Click **Submit & Verify Compliance**

The backend:
1. Loads crop-specific rules from `crop_rules.csv`
2. Validates all constraints:
   - `Yield >= MinYield`
   - `Pesticide <= MaxPesticide`
   - `Inventory >= MinInventory`
   - `MinTemperature <= Temperature <= MaxTemperature`
   - `MinPrice <= Price <= MaxPrice`
3. Generates a **Groth16 proof** via Circom/SnarkJS
4. Submits proof to `ComplianceRegistry` on local Ethereum
5. Stores in MongoDB: **Crop, Proof Hash, Verification Result, Timestamp**

### Regulator Dashboard (`/regulator`)

Shows only:
- Crop name
- Proof hash (truncated)
- Verification status (Verified / Failed)
- Timestamp
- Transaction hash

**Private farmer values are never displayed.**

## ZKP Circuit (`zkp/circuits/compliance.circom`)

**Private inputs:** yield, temperature, inventory, pesticide, price

**Public inputs:** minYield, maxPesticide, minInventory, minTemperature, maxTemperature, minPrice, maxPrice

Proves all 7 compliance constraints without revealing private values. Values are scaled by 1000 for integer arithmetic.

### Rebuild ZKP artifacts

```bash
cd zkp
npm run compile    # Compile Circom circuit
npm run setup      # Groth16 setup + export verifier
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `ZKP artifacts missing` | Run `cd zkp && npm run build` |
| `Contracts not deployed` | Start `npm run node` in contracts, then `npm run deploy` |
| `MongoDB connection failed` | Ensure `mongod` is running |
| `circom: command not found` | Install via `cargo install circom` |
| `Invalid ZKP proof` on-chain | Rebuild ZKP and redeploy verifier contract |
